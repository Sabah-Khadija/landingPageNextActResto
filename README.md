# Nextact Resto — Landing page (React + Vite)

```bash
npm install
npm run dev      # développement
npm run build    # production (dossier dist/)
```

- `src/data.js` : tous les textes et listes de la page
- `src/components/` : une section = un composant (animations GSAP / Lenis incluses)
- `src/Icons.jsx` : icônes SVG (arrière-plans des cartes + icônes des métiers)
- `src/index.css` : feuille de style d'origine + ajouts en fin de fichier
